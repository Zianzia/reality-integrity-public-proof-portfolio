# Declared Limitations

This portfolio intentionally separates demonstrated behavior from intended future capability.

## Current limitations

- No claim is made that private source repositories are ready to be made public.
- MGP-1 live authenticated webhook operation is not yet demonstrated end to end.
- MGP-1 production signing-key custody is not yet established.
- MGP-1 does not currently prove universal clone, fetch, theft, or exfiltration detection.
- MGP-1 does not currently provide automatic attacker attribution.
- Automatic remediation remains outside the demonstrated proof boundary.
- SCP-1 live Nosana execution remains unproven.
- SCP-1 live Solana anchoring remains unproven.
- No current proof should be described as regulatory certification or legal determination.
- No current proof should be described as a guarantee that AI systems cannot fail or be compromised.

## Operational posture

Where a capability has been exercised only locally or in simulation, public materials must say so explicitly.

Where a capability depends on external infrastructure that has not been executed live, public materials must say that execution remains unproven.

Where evidence exists, interpretation should remain bounded to what the evidence actually supports.
